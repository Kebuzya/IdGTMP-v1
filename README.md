# ГИДТПМ — Генератор идей для творческих проектов

Интерактивный веб-инструмент для генерации идей исследовательских и творческих проектов.

**Работает напрямую через файл `index.html` — без сервера, без сборки.**

## Локальный запуск

Достаточно открыть `index.html` двойным щелчком в браузере — никаких серверов не нужно.

## Возможности

- **Три режима:** Соло · Команда (до 10 чел.) · Случайный вызов
- **Две темы:** светлая «Академическая» (#F8F9FA) и тёмная «Лабораторная» (#1E1E2E)
- **Два языка:** RU / EN — переключение без перезагрузки
- **Экспорт:** копировать, скачать `.md`, поделиться (Web Share API)
- **Избранное:** сохранение идей в localStorage
- **Анимация «ИИ думает»** с меняющимися сообщениями
- **Восстановление состояния** после перезагрузки страницы

## Структура

```
index.html              главная страница
app.js                  ядро: темы, языки, навигация, загрузка
style.css               общие стили (адаптив 320–1200px)
theme-light.css         светлая тема
theme-dark.css          тёмная тема
data/
  interests.js          48 интересов (4 трека)
  skills.js             60+ навыков
  formats.js            14 форматов
  problems.js           100+ проблем
  methods.js            80+ методов
  applications.js       50+ областей применения
  roles.js              18 ролей
  templates.js          шаблоны названий и AI-комментариев
modes/
  solo.js               режим Соло
  team.js               режим Команда
  random.js             режим Случайный
utils/
  export.js             копирование, скачивание, шаринг, избранное
```

## Технологии

Vanilla JS (ES5-совместимый), HTML5, CSS3 с кастомными свойствами.  
Внешние зависимости: только шрифт Inter (Google Fonts).
